## Critical Findings (must-fix)

1. **[ARCH] Shared post Redux state causes data-race on homepage** — `MostLiked` and `PostList`/`HomeClient` all write to the same `state.posts.posts` array via separate `fetchMostLikedPosts` and `fetchRecommendedPosts` calls. The last API call to resolve overwrites the other, so the sidebar shows recommended posts or the feed shows top-5 items. `src/features/posts/components/MostLiked.tsx:94`, `src/app/(main)/HomeClient.tsx:18`

2. **[BUG] Comment icon 404 on Linux/production** — `PostCard.tsx:149` requests `/assets/icons/comment.svg` (lowercase) but the file is `Comment.svg` (uppercase). Case-insensitive on Windows; fatal on Linux. `src/features/posts/components/PostCard.tsx:149`

## Major Findings (should-fix)

3. **[QUAL] `LoginForm` bypasses `useAuth.login()`** — Dispatches `loginUser` directly and redirects; never fetches the user profile. `state.auth.user` stays `null` until the Navbar lazily calls `loadUser`. `src/features/auth/components/LoginForm.tsx:47`

4. **[QUAL] Homepage double-fetches recommended posts** — `HomeClient` calls `getRecommended` in its `useEffect` AND renders `<PostList>` which also calls `getRecommended`. Two API calls on every page load. `src/app/(main)/HomeClient.tsx:17-19`

5. **[ARCH] `fetchUserById` thunk fulfillment is a no-op** — `profileSlice.ts:134-136` case handler is empty; fetched data is silently discarded. Dead network call. `src/features/profile/profileSlice.ts:134`

6. **[QUAL] `EditProfileModal` uses `window.location.reload()`** — Full-page reload after profile update destroys client state. Should use `router.refresh()` + re-fetch via Redux. `src/features/profile/components/EditProfileModal.tsx:96`

7. **[QUAL] `EditProfileModal` uses `any` type** — `const updateData: any = {}` bypasses type safety. Should be typed as `UpdateProfileDto`. `src/features/profile/components/EditProfileModal.tsx:74`

8. **[QUAL] Bio field shown but never sent to API** — UI renders bio textarea with an inline "Note: Bio may not be saved" warning. `profile.service.ts` never includes bio in the FormData. Wire it up or remove it. `src/features/profile/components/EditProfileModal.tsx:187`

9. **[SEC] Auth cookie missing `Secure` flag** — `setAuthToken` sets cookie with `SameSite=Lax` only. In production HTTPS, the `Secure` attribute should be added to prevent transmission over HTTP. `src/lib/api.ts:112`

## Minor Findings (nice-to-fix)

10. **[QUAL] Dead empty stub files** — `src/features/posts/components/PostForm.tsx` and `src/features/auth/hooks/useLogin.ts` are both 1-line empty files. Should be deleted.

11. **[QUAL] Unused UI components** — `src/components/ui/Dropdown.tsx`, `DropdownItem.tsx`, and `Modal.tsx` are never imported anywhere. Dead code adding bundle surface area.

12. **[QUAL] Navbar typo in className** — `Navbar.tsx:165`: `"...grouh-30 w-30..."` — `grouh-30` is not a valid Tailwind class (likely a typo of `group`). `w-30` is also non-standard.

13. **[QUAL] Redundant type re-exports** — `types/index.ts:309-313` re-exports `User as UserType`, `Post as PostType`, `Comment as CommentType`. These are never used and only add confusion.

14. **[QUAL] `getPasswordStrength` exported but never used** — `src/utils/validation.ts:43` exports this function but no component imports it. Dead export.
